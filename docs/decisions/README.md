# Decisiones arquitectónicas (ADRs)

Índice de Architecture Decision Records del proyecto. Los agentes deben leer los ADRs en estado **Aceptado** antes de implementar o revisar código.

| ADR | Título | Estado |
|-----|--------|--------|
| [ADR-001](ADR-001-clean-architecture-solid.md) | Clean Architecture y principios SOLID en el backend .NET | **Aceptado** |

## Convenciones

- Nuevos ADRs: `ADR-NNN-<slug>.md` usando `agent-templates/adr-template.md`.
- Estado inicial siempre **Propuesto** (agentes no pueden marcar Aceptado).
- **Aceptado** solo por el Líder Técnico humano en PR dedicada.
- Si un ADR reemplaza otro, incluir campo `Supersedes: ADR-XXX`.
